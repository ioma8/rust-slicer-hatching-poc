# Project Name

This is a basic README file for the project "Rust hatching fill".

## Description

The "Project Name" project is a Rust program that generates hatched polygons. It uses the `image` and `imageproc` libraries to draw polygons and hatch them with lines. The program allows you to specify the number of points, width, and height of the polygon, as well as the spacing and angle of the hatch lines. It also supports cross-hatching.

## Installation

To run the program, you need to have Rust installed on your system. You can install Rust by following the instructions on the official Rust website: [https://www.rust-lang.org/tools/install](https://www.rust-lang.org/tools/install)

## Usage

To use the program, navigate to the project directory and run the following command:

```
cargo run
```

This will generate a random polygon and save the output image as "output.png" in the project directory.
